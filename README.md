# Sangkara Karya

Website resmi **Sangkara Karya**, studio digital independen berbasis di Garut, Indonesia.

Layanan: website bisnis, landing page, sistem web custom, website katalog/toko online, UI/UX dan redesign, serta maintenance dan optimasi.

## Menjalankan secara lokal

Website statis tanpa build step. Jalankan server lokal dari root repository:

\`\`\`bash
python3 -m http.server 8000
\`\`\`

Lalu buka http://localhost:8000.

## Publikasi

Repository ini menggunakan GitHub Pages dengan domain kustom yang tercatat di file \`CNAME\`: **allif.me**. Jangan menghapus file tersebut bila masih memakai domain yang sama.
